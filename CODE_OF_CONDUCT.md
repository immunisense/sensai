# Code of Conduct

This repository is the public issue tracker and docs for SensAI.

## Expected

- Be precise. Bugs need steps, versions, and expected vs actual.
- Stay on the product: CLI, IDE, SensAI-Agent, web, billing, docs.
- Assume good intent. Disagreement is fine; contempt is not.

## Not tolerated

- Harassment, hate, or personal attacks
- Publishing private data (tokens, cookies, backup codes, customer content)
- Exploit payloads, credential dumps, or instructions to attack a system
- Spam, advertising, or off-topic promotion

## Security

Vulnerabilities go to **security@immunisense.com**, never a public issue.

## Enforcement

Maintainers may edit, close, or lock issues and block accounts that break this policy. Reports: **legal@immunisense.com**.
