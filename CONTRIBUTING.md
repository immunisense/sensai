# Contributing

[https://github.com/immunisense/sensai](https://github.com/immunisense/sensai) is the **public docs and issue tracker** for SensAI. Source is proprietary and is not in this repository. Unsolicited pull requests are not accepted.

## Issues

Bugs and feature requests are welcome. Use a template so the product label is applied:

- [CLI bug](https://github.com/immunisense/sensai/issues/new?template=bug-cli.yml) — `sensai-cli` / TUI
- [IDE bug](https://github.com/immunisense/sensai/issues/new?template=bug-ide.yml) — SensAI IDE
- [Extension bug](https://github.com/immunisense/sensai/issues/new?template=bug-extension.yml) — SensAI-Agent (VS Code / Cursor / Windsurf)
- [Web bug](https://github.com/immunisense/sensai/issues/new?template=bug-web.yml) — [sensai.immunisense.com](https://sensai.immunisense.com/)
- [Feature](https://github.com/immunisense/sensai/issues/new?template=feature.yml)

Search existing issues first. One problem per issue. Include version, OS, and steps.

## Security

Do not open a public issue for a vulnerability. Email **security@immunisense.com**. See [`SECURITY.md`](SECURITY.md).

## Docs mistakes

Typo or outdated public docs: open an issue with the `documentation` label. Do not send a PR unless we asked for one.
